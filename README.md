# حكايات الإيمان – Hekayat Al Eman

> **رحلة بين قصص القرآن وعجائب الإيمان**

منصة إسلامية تعليمية وترفيهية تفاعلية (React + TypeScript + Express + SQLite + PWA) تقدم قصص الأنبياء والرسل والصحابة والسيرة النبوية ومعجزات الأنبياء وقصص القرآن عبر مشغل أفلام وثائقية متحرك مدمج داخل التطبيق بالكامل دون أي روابط يوتيوب خارجية، مع التزام صارم بالضوابط الشرعية.

---

## المزايا الرئيسية

1. **مشغل أفلام وثائقية متحرك مدمج (Zero YouTube):**
   - مشاهد تاريخية ومعمارية وصحراوية وبحرية متعددة اللقطات بتحريك كاميرا سينمائي (Ken Burns + مؤثرات بصرية مخصصة على Canvas).
   - تعليق صوتي عربي فصيح مع مؤثرات طبيعية مسموعة (الرياح، البحر، الصحراء، الوادي) دون موسيقى.
   - إيقاف فوري وحتمي للصوت والفيديو عند الخروج أو الانتقال بين الشاشات (`mediaPlaybackController`).
   - دعم الترجمة الثنائية (العربية / الإنجليزية / مزدوجة) واختيار الجودة (`1080p HD` / `720p HD` / `480p` / `360p`).

2. **المكتبات والمحتوى التوثيقي الشامل:**
   - **قصص الأنبياء والرسل (25 نبياً ورسولاً)** بالترتيب التاريخي مع الأحداث والدعوة والمعجزات والابتلاءات.
   - **مكتبة معجزات الأنبياء (12 معجزة)** موثقة بالآيات والأحاديث والتحقيق العلمي.
   - **قصص الصحابة الكرام (11 سيرة)**: أبو بكر الصديق، عمر بن الخطاب، عثمان بن عفان، علي بن أبي طالب، خالد بن الوليد، بلال بن رباح، مصعب بن عمير، سعد بن أبي وقاص، خديجة بنت خويلد، عائشة بنت أبي بكر، وأسماء بنت أبي بكر رضي الله عنهم.
   - **السيرة النبوية الشريفة (10 مراحل زمنية)** من المولد والشباب إلى الوحي والهجرة وفتح مكة وحجة الوداع.
   - **قصص القرآن الكريم (9 قصص)** تشمل أصحاب الكهف، أصحاب الفيل، قارون، أصحاب الأخدود، طالوت وجالوت، مريم عليها السلام، لقمان الحكيم، ذي القرنين، وأصحاب الجنة.
   - **الرسالة الإيمانية اليومية المتغيرة** + **البحث الشامل الموحّد** عبر جميع الأقسام.
   - **اختبارات تفاعلية (5 أسئلة على الأقل لكل قصة)** + نظام النقاط التعليمية والشارات والمستويات.

3. **المساعد التعليمي التفاعلي «رفيق الإيمان» (`/api/companion`):**
   - يستند إلى قاعدة المعرفة الموثقة ونموذج `gemini-4-hydrogen` على الخادم (مع مسار احتياطي موثق عند غياب المفتاح أو نفاد الحصة).
   - مزوّد بآلية حماية شرعية تمنع اختلاق الآيات أو الأحاديث، وتحيل أسئلة الفتاوى الفقهية الخاصة إلى أهل العلم والهيئات الشرعية المختصة.

4. **ركن الأطفال + حساب المستخدم + لوحة الإدارة والمراجعة الشرعية:**
   - حساب المستخدم يضم النقاط، الأوسمة، التفضيلات المتزامنة، المفضلة، سجل المشاهدة، ونموذج **الإبلاغ عن خطأ علمي أو تاريخي** (`POST /api/reports`).
   - لوحة الإدارة تتضمن مراجعة القصص، إدارة الحلقات، مراجعة **بلاغات الدقة** (`PATCH /api/reports/:id`)، و**استوديو الذكاء الاصطناعي** مع توضيح مراحل الإنتاج الإحدى عشرة.

---

## الضوابط الشرعية المطبقة في المنصة

- **منع تجسيد الأنبياء والرسل منعاً باتاً** (لا وجوه ولا أجساد؛ المشاهد مبنية على الطبيعة والعمارة والرموز البصرية الآمنة).
- **الالتزام بالقرآن الكريم والسنة الصحيحة** ومصادر التفسير والتاريخ المعتمدة كابن كثير، مع بيان الروايات المختلف فيها بوضوح.
- **إحالة الفتاوى الفقهية** في المساعد الذكي «رفيق الإيمان» إلى العلماء ودور الإفتاء المختصة.
- **المؤثرات الصوتية الطبيعية فقط** (رياح، أمواج بحر، صحراء) بدون أي معازف أو موسيقى.

## البنية التقنية وقاعدة البيانات

- **الواجهة الأمامية:** React 19, TypeScript, Tailwind CSS v4, Vite, Lucide Icons, `vite-plugin-pwa`.
- **الخادم:** Express (`server.ts`) على المنفذ `3000`.
- **قاعدة البيانات (`node:sqlite` في `data/rihlat.db`):**
  - `prophets_store`, `categories_store`
  - `users`, `sessions`
  - `user_progress`, `user_favorites`, `user_quiz_scores`, `user_preferences`
  - `content_reports`, `studio_drafts`

### نقاط API الرئيسية

| المسار | الوظيفة |
| --- | --- |
| `GET /api/prophets` | جلب كتالوج الأنبياء والتصنيفات من SQLite |
| `GET /api/user/state` | جلب سجل المشاهدة، المفضلة، درجات الاختبارات، وتفضيلات المستخدم |
| `PUT /api/user/preferences` | حفظ الاسم الرمزي، الصورة الرمزية، لغة الترجمة، الجودة، والتنبيهات |
| `POST /api/companion` | محادثة المساعد التعليمي «رفيق الإيمان» مع المصادر وضابط الفتوى |
| `POST /api/narrate` | توليد التعليق الصوتي العربي عبر Gemini TTS مع وضع النطق البديل |
| `POST /api/generate-documentary` | توليد سيناريو وثائقي مراجع شرعياً في الاستوديو |
| `GET/POST /api/reports` & `PATCH /api/reports/:id` | إرسال ومراجعة بلاغات الدقة العلمية |

## التشغيل والتطوير محلياً

```bash
npm install
npm run dev
```

سيعمل التطبيق وخادم API معاً على `http://localhost:3000`.

### متغيرات البيئة الاختيارية (`.env`)

راجع `.env.example`:
- `GEMINI_API_KEY`: لتفعيل التعليق الصوتي الذكي، استوديو السيناريو، ومحادثة «رفيق الإيمان».
- `ADMIN_ACCESS_CODE`: رمز حماية اختياري للوحة الإدارة.

### تشغيل الاختبارات والتحقق

```bash
npx --yes tsx --test src/utils/prophetsLogic.test.ts
npm run lint
npm run build
```

## التثبيت على Android وبناء APK عبر Capacitor

التطبيق يدعم التثبيت المباشر كـ **PWA** على أجهزة Android عبر متصفح Chrome («إضافة إلى الشاشة الرئيسية»).
ولإنشاء حزمة `app-release.apk` أصلية عبر **Capacitor / Android Studio** (على بيئة تحتوي على Android SDK وJava JDK):

```bash
npm run build
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap add android
npx cap sync android
cd android && ./gradlew assembleRelease
```

> **ملاحظة شفافة:** هذه البيئة السحابية تُنتج حزمة الويب والتطبيق التفاعلي `dist/` وملف التهيئة `capacitor.config.ts` دون تجميع ثنائي لملف `.apk` على الخادم لعدم توفر Android SDK/Gradle محلياً في الحاوية؛ ويمكنك توليد الـ `.apk` مباشرة بتشغيل الأوامر أعلاه على جهازك أو في CI/CD يحتوي على Android SDK.
